შაკუჰაჩის აპი - ატვირთვა GitHub Pages-ზე

1. GitHub-ზე შექმენი ახალი საჯარო (Public) რეპოზიტორია, მაგ. სახელით: shakuhachi
2. ატვირთე ყველა ფაილი და საქაღალდე ამ არქივიდან (index.html, manifest.webmanifest, sw.js, icons/).
   ვებ-გვერდზე: Add file -> Upload files, გადმოიტანე ფაილები, დააჭირე Commit changes.
3. რეპოში: Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, საქაღალდე: / (root) -> Save.
4. ერთ-ორ წუთში მისამართი გამოჩნდება: https://შენი-სახელი.github.io/shakuhachi/
5. ტელეფონზე Chrome-ით გახსენი ეს მისამართი -> მენიუ (3 წერტილი) -> "Install app" ან "Add to Home screen".
   შემდეგ ხატულა მთავარ ეკრანზე გამოჩნდება და აპი ოფლაინშიც იმუშავებს (პირველად ინტერნეტით გახსენი).

განახლებისას: ჩაანაცვლე index.html რეპოში და sw.js-ში შეცვალე ვერსია (v1 -> v2),
რომ ტელეფონმა ახალი ვერსია ჩამოტვირთოს.
შენი კომპოზიციები ტელეფონის ბრაუზერში ინახება და რეპოში არ ხვდება.
